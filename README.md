Atuo na área há mais de 3 anos, sempre buscando evoluir, escrever código de qualidade e entender de verdade como as coisas funcionam. Minha jornada passa pelo desenvolvimento front-end e back-end, estudando, criando, errando, acertando e construindo soluções que realmente fazem sentido.
